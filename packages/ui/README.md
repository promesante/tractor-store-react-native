# @tractor/ui

Shared UI for all teams, built on [Gluestack UI](https://gluestack.io/) v3 and NativeWind 4.

`src/gluestack` holds Gluestack components copied from the `main-v3` branch of
[gluestack-ui](https://github.com/gluestack/gluestack-ui/tree/main-v3/apps/starter-kit-expo/components/ui),
which is what `npx gluestack-ui@3 add <component>` copies. They are kept unchanged, so they can
be updated from upstream.
